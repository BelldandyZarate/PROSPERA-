# PROSPERA+ — Sistema Integral de Apoyo y Punto de Venta Social

PROSPERA+ es un sistema web integral desarrollado para centralizar y facilitar la administración de beneficiarios, productos, inventario, ventas, pedidos y servicios de apoyo social. La plataforma permite gestionar diferentes perfiles de usuario mediante un sistema de roles y permisos, optimizando la organización de la información y los procesos administrativos.

El proyecto contempla módulos para la gestión de beneficiarios, punto de venta, inventario, productos, pedidos, usuarios, servicios de consultoría y administración general, buscando proporcionar una solución digital escalable y organizada.

### 🛠️ Tecnologías y herramientas

* **Frontend:** React, Vite, JavaScript, HTML5, CSS3
* **Backend:** PHP
* **Base de datos:** MySQL
* **Control de versiones:** Git y GitHub
* **Diseño y documentación:** UML, diagramas de casos de uso y modelado de base de datos

### 📌 Principales funcionalidades

* Gestión y registro de beneficiarios.
* Administración de productos e inventario.
* Gestión de ventas y pedidos.
* Administración de usuarios, roles y permisos.
* Gestión de servicios de consultoría.
* Control de operaciones del punto de venta social.
* Centralización de información administrativa.
* Diseño de base de datos relacional.
* Arquitectura orientada a la organización y escalabilidad del sistema.
